Studying (procrastination) protocol

  1. Make a list and break it into actionable tasks. Set one measurable goal for this session.
  2. Use the distraction sheet to log anything distracting - use it for urge surfing: sit with the thought, don't act on it.
  3. Work 20-50 minutes. Break should be about a third to a quarter of your work time. No social media or music during the break.
  4. Start the timer and sit in silence for 1 minute. Process any negative emotions while keeping the task in mind.
  5. Minimal viable goal: commit to the task for just 1 minute. You can stop after - use the unfinished work incentive to keep going.
If you're tired, take a 20-minute nap instead of pushing through.
